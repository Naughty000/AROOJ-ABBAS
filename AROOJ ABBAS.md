# Arooj Abbas: Portfolio

**Live portfolio:** https://naughty000.github.io/AROOJ-ABBAS

## About this portfolio

A simple, responsive portfolio for Arooj Abbas, a final-year Computer Science student and backend developer building agentic AI systems. It presents my Final Year Project, ARIA, alongside my web development projects, experience, skills and CV. Built with plain HTML, CSS and JavaScript, with no frameworks and no build step.

## Features

- **Responsive layout:** works on desktop, tablet and mobile.
- **Automatic dark and light mode:** follows the visitor's device setting.
- **Featured project:** ARIA, with a diagram of how its LangGraph router dispatches requests to four agents.
- **Projects, experience and education:** taken directly from my CV.
- **CV download:** one-click PDF download.
- **Direct contact links:** email, phone, LinkedIn and GitHub.
- **Accessible by default:** semantic HTML, keyboard focus styles and reduced-motion support.

## Technologies used

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** CSS Grid, Flexbox, custom properties
- **Fonts:** Google Fonts (Bricolage Grotesque, Instrument Sans)
- **Deployment:** GitHub Pages

## Projects featured

1. **ARIA: AI Research & Intelligent Assistant** (Final Year Project, in development): a multi-agent desktop assistant built around a LangGraph tool router. I own four agents: Gmail Email Agent, WhatsApp Messaging Agent, Document Summarizer and Browser Automation. Built with Python, LangChain, LangGraph, Groq API, ChromaDB, Whisper and Playwright.
2. **Restaurant Management System** (in progress): full-stack platform with role-based views for orders and updates. React.js, Node.js.
3. **Personal Finance Tracker:** expense tracking with Chart.js visualisations. JavaScript, HTML5, CSS3.
4. **Health Tracking Application:** calorie counter with meal planning and nutrition tracking. JavaScript, HTML5, CSS3.

## Deployment

The site is deployed with GitHub Pages:

1. Repository: `AROOJ-ABBAS`, with all files in the root folder.
2. In Settings > Pages, deploy from the `main` branch and the `/ (root)` folder.
3. Every push to `main` updates the live site automatically.
4. Available at https://naughty000.github.io/AROOJ-ABBAS

To run it locally, open `index.html` in a browser.
